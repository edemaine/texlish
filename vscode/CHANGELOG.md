# Texlish VSCode Extension Changelog

## Unreleased

* Highlight `***` and longer emphasis delimiters as complete star runs.
  Runs of three or more stars use bold italic highlighting.
* Stop highlighting underscore emphasis, which Texlish does not support.

## 0.3.0

* Syntax highlighting and indentation support for Texlish 0.3.0,
  including `::list`, `::table`, and Markdown-style strikethrough.

## 0.2.0

* Syntax highlighting and indentation support for Texlish 0.2.0.

## 0.0.0

* Initial working version with basic syntax highlighting
